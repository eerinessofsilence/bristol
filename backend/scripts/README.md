# Оновлення ставок мита

Runtime калькулятора читає `app/data/duty_rates.json` і не звертається до
сторонніх сайтів.

Раз на місяць або після зміни Митного тарифу:

1. Завантажте у форматі `htm` або `zip` чинні таблиці
   [груп 01–49](https://zakon.rada.gov.ua/laws/show/2697%D0%B0-20#Text) та
   [груп 50–97](https://zakon.rada.gov.ua/laws/show/2697%D0%B1-20#Text).
2. Перебуваючи в каталозі `backend`, виконайте:

   ```bash
   python scripts/build_duty_rates.py \
     --groups-01-49 /path/to/groups-01-49.zip \
     --groups-50-97 /path/to/groups-50-97.zip
   ```

3. Перегляньте diff, запустіть тести та вибірково звірте критичні коди:

   ```bash
   python scripts/verify_duty_rate.py 8501710090
   ```

Скрипт збирає ставки лише для кодів із локального довідника ризиків і
зупиняється, якщо хоча б один код відсутній або ставка не є звичайним
відсотком.

У калькуляторі використовується базова **пільгова** ставка. Преференційна
ставка за країною походження (зокрема 0%) тут не застосовується: для неї
потрібні окремі поля країни, торговельної угоди та документа про походження.
